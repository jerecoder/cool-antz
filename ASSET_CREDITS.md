# Asset Credits

The included sprites can be replaced by files with the same names in
`ant_byte_env/assets/`.

| File | Asset name | Author | Source URL | License |
| --- | --- | --- | --- | --- |
| `ant_byte_env/assets/ant.png` | User-provided pixel ant sprite | User-provided | Copied into this repository | Source/license not supplied |
| `ant_byte_env/assets/food.png` | User-provided pixel cookie food sprite | User-provided | Copied into this repository | Source/license not supplied |
| `ant_byte_env/assets/hub.png` | Generated placeholder hub sprite | cool-antz contributors | This repository | CC0-1.0 compatible dedication |
| `ant_byte_env/assets/tile.png` | Generated placeholder tile sprite | cool-antz contributors | This repository | CC0-1.0 compatible dedication |

Suggested replacement sources:

- OpenGameArt CC0 ant or insect sprites, such as a walking ant sprite.
- OpenGameArt CC0 food or icon sprites.
- Kenney CC0 tile, terrain, or board-game assets.

When replacing assets, update this file with exact asset names, authors, source
URLs, and licenses.
