# Informe del proyecto final de RL

Este directorio contiene el borrador en LaTeX y las figuras reproducibles del
informe.

Comandos:

```bash
cd report
make figures
make
```

El script `scripts/build_figures.py` lee artefactos locales bajo `runs/`,
`experiments/` y `docs/media/`. Las fuentes resumidas quedan en
`data/figure_sources.md` y en los CSV de `data/`.
